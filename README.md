 Linux-Security-Reconnaissance

 1. Introduction to Linux
Linux is an open-source operating system used in servers, networking and cybersecurity.

2. Basic Linux Commands
- pwd – Shows current directory.
- ls – Lists files and folders.
- cd – Changes directory.
- mkdir – Creates a directory.
- touch – Creates a file.
- whoami – Shows current username.

 3. Linux File Permissions
Linux uses three basic permissions:
- Read (r)
- Write (w)
- Execute (x)

4. Security Tools
Some commonly used cybersecurity tools are:
- Wireshark
- Nmap
- Burp Suite
- Metasploit

5. Reconnaissance
Reconnaissance is the process of collecting information during an authorized security assessment.

 6. Network Security
Network security protects computer networks from unauthorized access and threats.

## 7. Conclusion
Linux, security tools and reconnaissance are important foundations for learning cybersecurity and networking.
